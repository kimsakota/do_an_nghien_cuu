## Block conventions

- **Callout** phân loại intent: todo, question, warning, danger, success, example, quote.
- **Block ID** neo statement quan trọng để embed nơi khác.
- **Embed** tái sử dụng một block thay vì copy.
- **Mermaid** mô tả workflow/architecture.
- **Query** tìm task native.
- **Base embed** hiển thị dashboard động từ properties.
- **Task** chỉ dùng cho action; kiến thức không biến thành checkbox.

> [!tip] Cách dùng
> Tạo note đúng folder → mở Command Palette → **Templates: Insert template** → chọn template → điền property và các placeholder.
